# Экспорт заказов в CSV — Задачи

Реализуют асинхронный экспорт в CSV из [спецификации](./spec.md); до раскатки всё за флагом `orders_csv_export`.

## Задачи

- [ ] **T1. Добавить таблицу `order_exports` и фича-флаг**
  - Покрывает: `setup`
  - Файлы: новая миграция для `order_exports`, конфиг флага `orders_csv_export`
  - Что сделать: создать таблицу, как в разделе «Модель данных» спецификации; зарегистрировать флаг, по умолчанию выключен
  - Готово, когда: миграция применяется и откатывается на локальной БД без ошибок; флаг читается в коде и выключен
  - Зависит от: —
- [ ] **T2. Реализовать воркер экспорта**
  - Покрывает: R2, R3
  - Файлы: `workers/orders-export.ts`, `workers/orders-export.test.ts`
  - Что сделать: задача, которая строит запрос через `OrdersFilter`, потоково читает строки курсором БД пачками по 1k и загружает CSV (раздел «Компоненты и изменения»)
  - Готово, когда: проходят unit-тесты форматирования CSV; интеграционный тест показывает, что строки экспорта совпадают с результатом `GET /api/orders` для каждой комбинации фильтров
  - Зависит от: T1
- [ ] **T3. Добавить API экспорта**
  - Покрывает: R1
  - Файлы: `api/orders/exports.ts`, `api/orders/exports.test.ts`
  - Что сделать: `POST /api/orders/exports` и `GET /api/orders/exports/{id}`, как в разделе «API / интерфейсы», с лимитом в 3 одновременных экспорта на мерчанта
  - Готово, когда: тесты покрывают `202 { exportId }`, опрос статуса с подписанной ссылкой `url` и `429` на четвёртый одновременный экспорт
  - Зависит от: T2
- [ ] **T4. Добавить кнопку экспорта на страницу Orders**
  - Покрывает: R1
  - Файлы: `web/pages/orders/ExportButton.tsx`
  - Что сделать: кнопка запускает экспорт с текущими фильтрами, опрашивает статус и скачивает файл; показывается, только если включён `orders_csv_export`
  - Готово, когда: при включённом флаге экспорт с фильтрами скачивает `.csv`; если ничего не найдено, интерфейс показывает «No orders match your filters»; при выключенном флаге кнопки нет
  - Зависит от: T3
- [ ] **T5. Отправлять ссылку на почту для долгих экспортов**
  - Покрывает: R4
  - Файлы: `workers/orders-export.ts`, `workers/orders-export.test.ts`
  - Что сделать: переиспользовать существующую задачу отправки писем, чтобы отправлять ссылку на скачивание, если задача идёт дольше 10 с
  - Готово, когда: тест с задачей дольше 10 с отправляет ровно одно письмо со ссылкой; быстрая задача не отправляет ни одного
  - Зависит от: T2
- [ ] **T6. Добавить события экспорта и алерт на ошибки**
  - Покрывает: `setup`
  - Файлы: `workers/orders-export.ts`, конфиг алертов
  - Что сделать: отправлять `orders_export_started` / `orders_export_finished` с `row_count` и `duration_ms`; алерт, если доля ошибок выше 5% за 1 ч (раздел «Наблюдаемость»)
  - Готово, когда: оба события видны в отладчике аналитики для локального экспорта; правило алерта есть в конфиге алертов
  - Зависит от: T3
- [ ] **T7. Провести нагрузочный тест на стейджинге**
  - Покрывает: R3
  - Файлы: скрипт нагрузочного теста для фикстуры на 100 тыс. заказов
  - Что сделать: запустить экспорт 100 тыс. заказов на стейджинге с включённым флагом для тестового мерчанта
  - Готово, когда: экспорт завершается быстрее чем за 2 минуты
  - Зависит от: T4, T6
- [ ] **T8. Раскатить**
  - Покрывает: `rollout`
  - Файлы: конфиг флага `orders_csv_export`
  - Что сделать: внутренние магазины → 10% мерчантов → 100% за две недели (раздел «Раскатка и откат»)
  - Готово, когда: флаг включён на 100%, и алерт на ошибки молчит неделю
  - Зависит от: T7
  - Заблокировано: Spec Q1
