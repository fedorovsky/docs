# Экспорт заказов в CSV — PRD

## Кратко

Мерчанты могут скачать свои заказы в CSV со страницы «Заказы» и сверять продажи в своих бухгалтерских инструментах, не запрашивая выгрузку у поддержки.

## Проблема

Мерчанты сверяют заказы в таблицах или бухгалтерских программах. Сейчас получить данные можно только через поддержку: она вручную выполняет запрос. В прошлом квартале поддержка обработала 140 таких запросов (≈ 9% всех тикетов), медианное время ответа — 2 дня. На интервью мерчанты рассказали, что эта задержка блокирует им закрытие месяца.

## Цели

- Мерчанты получают данные о заказах без обращения в поддержку.
- Снизить число тикетов поддержки про выгрузку данных.

## Вне рамок

- Экспорт по расписанию / автоматический экспорт.
- Форматы кроме CSV (Excel, JSON).
- Экспорт товаров, клиентов или выплат — только заказы.

## Пользователи и сценарии

- Как мерчант, я хочу экспортировать заказы, которые сейчас вижу, чтобы импортировать их в свою бухгалтерскую программу.
- Как мерчант с большим магазином, я хочу, чтобы экспорт работал для заказов за целый год и страница при этом не зависала.

## Требования

| ID | Требование | Приоритет | Критерии приёмки |
|----|------------|-----------|------------------|
| R1 | Мерчант может экспортировать заказы со страницы «Заказы» в CSV | Must | Кнопка «Экспорт CSV» на странице «Заказы» отдаёт файл `.csv` для скачивания |
| R2 | Экспорт учитывает применённые фильтры (период, статус) | Must | Строки в выгрузке в точности совпадают со строками отфильтрованного списка |
| R3 | Экспорт работает для объёма до 100 тыс. заказов | Must | Экспорт 100 тыс. заказов завершается, и мерчант получает файл без таймаута страницы |
| R4 | Мерчант получает уведомление, когда большой экспорт готов | Should | Если экспорт не завершился сразу, мерчант получает письмо со ссылкой на скачивание |
| R5 | ~~Мерчант может выбрать, какие колонки экспортировать~~ | — | Отменено 2026-03-09: на интервью спроса не было; вернёмся после запуска |

## Метрики успеха

| Метрика | Базовое значение | Цель | Как измеряем |
|---------|------------------|------|--------------|
| Тикеты поддержки с тегом «выгрузка данных» за квартал | 140 | < 30 | Отчёт по тегам в хелпдеске |
| Мерчанты, которые пользуются экспортом хотя бы раз в месяц | 0 | неизвестно — см. открытые вопросы | Событие `orders_export_started` |
