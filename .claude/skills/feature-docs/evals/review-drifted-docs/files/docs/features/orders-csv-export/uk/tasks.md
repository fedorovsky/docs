# Експорт замовлень у CSV — Завдання

Реалізують асинхронний експорт у CSV зі [специфікації](./spec.md). Кнопка Export іде останньою, тому до навантажувального тесту бекенду ніщо не доступне.

## Завдання

- [ ] **T1. Додати таблицю `order_exports`**
  - Покриває: `setup`
  - Файли: нова міграція для `order_exports`
  - Що зробити: створити таблицю, як у розділі «Модель даних» специфікації
  - Готово, коли: міграція застосовується і відкочується на локальній БД без помилок
  - Залежить від: —
- [ ] **T2. Реалізувати воркер експорту**
  - Покриває: R2, R3
  - Файли: `workers/orders-export.ts`, `workers/orders-export.test.ts`
  - Що зробити: задача, яка будує запит через `OrdersFilter`, потоково читає рядки курсором БД пачками по 1k і завантажує CSV (розділ «Компоненти та зміни»)
  - Готово, коли: проходять unit-тести форматування CSV; інтеграційний тест показує, що рядки експорту збігаються з результатом `GET /api/orders` для кожної комбінації фільтрів
  - Залежить від: T1
- [ ] **T3. Додати API експорту**
  - Покриває: R1
  - Файли: `api/orders/exports.ts`, `api/orders/exports.test.ts`
  - Що зробити: `POST /api/orders/exports` і `GET /api/orders/exports/{id}`, як у розділі «API / інтерфейси», з лімітом у 3 одночасні експорти на мерчанта
  - Готово, коли: тести покривають `202 { exportId }`, опитування статусу з підписаним посиланням `url` і `429` на четвертий одночасний експорт
  - Залежить від: T2
- [ ] **T4. Надсилати посилання на пошту для довгих експортів**
  - Покриває: R4

  - Що зробити: перевикористати наявну задачу надсилання листів, щоб надсилати посилання на завантаження, якщо задача триває довше 10 с
  - Готово, коли: тест із задачею довше 10 с надсилає рівно один лист із посиланням; швидка задача не надсилає жодного
  - Залежить від: T2
- [ ] **T5. Додати події експорту й алерт на помилки**
