# Експорт замовлень у CSV — PRD

## Коротко

Мерчанти можуть завантажити свої замовлення у CSV зі сторінки «Orders» і звіряти продажі у своїх бухгалтерських інструментах, не запитуючи вивантаження у підтримки.

## Проблема

Мерчанти звіряють замовлення в таблицях або бухгалтерських програмах. Сьогодні отримати дані можна лише через підтримку: вона вручну виконує запит. Минулого кварталу підтримка обробила 140 таких запитів (≈ 9% усіх тікетів), медіанний час відповіді — 2 дні ([звіт підтримки](https://helpdesk.example.com/reports/orders-export-requests)). На [інтерв’ю](https://wiki.example.com/research/merchant-interviews-2026-02) мерчанти розповіли, що ця затримка блокує їм закриття місяця.

## Цілі

- Мерчанти отримують дані про замовлення без звернення до підтримки.
- Зменшити кількість тікетів підтримки щодо вивантаження даних.

## Поза межами

- Експорт за розкладом / автоматичний експорт.
- Формати, крім CSV (Excel, JSON).
- Експорт товарів, клієнтів або виплат — лише замовлення.

## Користувачі та сценарії

- Як мерчант, я хочу експортувати замовлення, які зараз бачу, щоб імпортувати їх у свою бухгалтерську програму.
- Як мерчант із великим магазином, я хочу, щоб експорт працював для замовлень за цілий рік і сторінка при цьому не зависала.

## Вимоги

| ID | Вимога | Пріоритет | Критерії приймання |
|----|--------|-----------|--------------------|
| R1 | Мерчант може експортувати замовлення зі сторінки «Orders» у CSV | Must | Кнопка «Export CSV» на сторінці «Orders» віддає файл `.csv` для завантаження |
| R2 | Експорт враховує застосовані фільтри (період, статус) | Must | Рядки у вивантаженні точно збігаються з рядками відфільтрованого списку |
| R3 | Експорт працює для обсягу до 100 тис. замовлень | Must | Експорт 100 тис. замовлень завершується, і мерчант отримує файл без таймауту сторінки |
| R4 | Мерчант отримує сповіщення, коли великий експорт готовий | Should | Якщо експорт не завершився одразу, мерчант отримує лист із посиланням на завантаження |
| R5 | ~~Мерчант може обрати, які колонки експортувати~~ | — | Скасовано 2026-03-09: на інтерв’ю попиту не було; повернемося після запуску |
